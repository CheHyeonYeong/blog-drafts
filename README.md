# 블로그 원고

티스토리와 벨로그에 발행할 원고를 작성하고 수정 이력을 관리합니다.

- `초안/`: 작성 중인 원고
- `발행완료/`: 발행한 원고와 이후 수정본
- `assets/`: 여러 원고에서 공유하는 이미지와 첨부파일

[[블로그/초안/원고 템플릿|원고 템플릿]]을 복사해서 새 글을 작성합니다. 발행 후에는 원고를 `발행완료/`로 옮기고 발행 URL을 기록합니다.

옵시디언에 붙여넣는 새 이미지는 현재 노트 폴더 아래 `assets/`에 저장됩니다. 예를 들어 초안의 이미지는 `초안/assets/`에 저장되어 원고와 함께 Git으로 관리됩니다. 원고를 이동할 때는 옵시디언에서 이동하여 이미지 링크가 갱신되도록 합니다.

플랫폼의 발행본 자동 백업은 기존 저장소에서 관리합니다.
