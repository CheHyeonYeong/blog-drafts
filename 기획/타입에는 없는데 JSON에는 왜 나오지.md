# 후속 글 — 타입에는 없는데 JSON에는 왜 나오지?

출발 글: [[블로그/초안/블로그 - 타입을 지정했는데 추가 필드는 왜 통과할까]]

핵심 질문: 타입에서 추가 필드가 보이지 않아도 실제 객체에는 남는다. 런타임에서 제거하거나 거부하려면 무엇을 해야 할까?

- `Reply` 타입으로 대입한 객체를 JSON으로 출력하며 시작한다.
- 같은 입력으로 Valibot의 `object`(출력에서 제외), `strictObject`(검증 실패), `looseObject`(보존), `objectWithRest`(추가 값도 검사)를 비교한다.
- 파싱 결과를 버리고 원본을 반환하는 실수를 보여준다.
- 중첩 객체의 정책은 각 스키마에 달려 있음을 설명한다.
- `InferOutput`으로 타입을 얻는 것과 실제 파싱을 실행하는 것은 구분한다.

기존 장문과 검증된 예제는 Git 커밋 `f0c417e`의 원고에 남아 있다. 후속 글에는 런타임 정책에 필요한 부분만 가져온다.

제네릭·함수 타입 표기 비교와 Exact 유틸리티는 이 후속 글에도 넣지 않는다. 별도 글감으로 보관한다.
